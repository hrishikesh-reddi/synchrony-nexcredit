# NexCredit AI

Real-time, multi-modal credit-underwriting prototype built for the Synchrony hackathon
(**Next-Gen Credit Intelligence: Building a Real-Time, Multi-Modal Underwriting Engine**).

A Spring Boot + React application that evaluates New-to-Credit and thin-file applicants
using alternative-data signals, with explainable decisions, a human-review queue, JWT
authentication, and PostgreSQL + pgvector semantic document search.

See `README.md` for the architecture, run instructions, API surface, and responsible-AI posture.
